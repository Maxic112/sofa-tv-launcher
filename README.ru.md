# Sofa TV Launcher

Лёгкий главный экран для Android TV со встроенным переназначением кнопок пульта.

[English version](README.md)

Sofa TV заменяет сразу три приложения: лаунчер, переназначатель кнопок и таймер сна. Сделан
для слабых телевизоров и приставок с 2 ГБ памяти и меньше: обычные View Android, без Compose
и Leanback, один процесс, программная отрисовка по умолчанию. На 2-гигабайтном ТВ TCL на экране
занимает около 25 МБ (PSS).

## Возможности

- **Главный экран.** Сверху избранное, ниже все приложения по алфавиту. Плитки 16:9 — баннер
  приложения для ТВ или рамка с его иконкой. Число столбцов и высота плиток настраиваются.
  Долгое нажатие OK на плитке — в избранное, переместить, скрыть, о приложении, удалить.
- **Переназначение кнопок пульта.** Нажмите любую кнопку, которую видит служба спецвозможностей,
  и назначьте действия на одиночное, двойное нажатие и удержание: запуск приложения, ярлык,
  свой Intent или ссылка, системные действия (назад, недавние, уведомления, громкость,
  медиакнопки, меню питания, сон) и действия самого лаунчера. Исключения по приложениям.
  Если что-то сломалось — удерживайте «Громкость −» 7 секунд, переназначение выключится.
- **Перехват Home.** Кнопка Home открывает Sofa TV без отключения штатного лаунчера.
- **Панель состояния.** Строка на главном экране и панель поверх приложений: часы, таймер сна,
  ОЗУ, swap, диск, температура и частота CPU, скорость сети, Wi-Fi или Ethernet, IP-адрес.
- **Таймер сна** с предупреждением за минуту и возможностью продлить.
- **Очистка памяти**: стандартная выгрузка фоновых процессов, Safety Guard (TCL) или
  принудительная остановка через системные настройки (её выполняет служба спецвозможностей, без root).
- **Языки:** английский и русский; по умолчанию как в системе, меняется в настройках.
- **Обновления из GitHub Releases.** Проверяются раз в сутки; когда вышла новая версия, на главном
  экране появляется кнопка «Обновить» с оранжевой точкой. В «Настройки → Обновления» — версия,
  проверка по запросу и установка обновления.

## Требования

- Android TV 7.0 и новее (API 24+).
- Переназначению кнопок, перехвату Home, панели поверх приложений, таймеру сна и принудительной
  остановке нужна служба «Sofa TV: кнопки пульта», включённая в спецвозможностях ТВ.
  Главный экран работает и без неё.

## Установка

Скачайте APK из [Releases](../../releases) и установите, например, по ADB:

```bash
adb connect <ip-тв>:5555
adb -s <ip-тв>:5555 install -r sofa-tv-launcher.apk
```

Затем нажмите Home и выберите Sofa TV или включите «Перехват Home» в его настройках.

Следующие версии ставятся из самого приложения («Настройки → Обновления»). В первый раз Android
попросит разрешить Sofa TV устанавливать приложения.

## Сборка

Нужны JDK 17+ и Android SDK (`ANDROID_HOME` или `sdk.dir` в `local.properties`).

```bash
./build.sh                 # release APK в app/build/outputs/apk/release/
./build.sh install <ip-тв> # собрать, установить по ADB и открыть
```

Подпись release берёт `sofatv.storeFile`, `sofatv.storePassword`, `sofatv.keyAlias` и
`sofatv.keyPassword` из `~/.gradle/gradle.properties`. Без них release подписывается debug-ключом.

Адрес проверки обновлений по умолчанию — последний релиз этого репозитория на GitHub. Тестовую сборку
можно направить на локальный сервер с тем же JSON: `-Psofatv.updateUrl=http://<ip>:8000/latest.json`.

## Конфиденциальность

У Sofa TV нет аналитики и рекламы. В сеть он ходит только за проверкой обновлений на GitHub раз
в сутки. Подробнее — [PRIVACY.md](PRIVACY.md).
